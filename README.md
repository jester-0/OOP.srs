СӨЖ 1 — Инкапсуляция қағидаттарына негізделген класс жобалау 
ТАӘ: Жантлек Жандос Жанболатұлы 
Топ: ПИ-1 
Нұсқа: № 6 — Қызметкер (Сотрудник) 
Тапсырма бойынша қысқаша түсінік Бұл жобада Сотрудник (Қызметкер) классы жобаланды. Класс объекта бағытталған бағдарламалаудың негізгі принцип көрсетеді: Инкапсуляция — барлық өрістер (полное имя, должность, зарплата, история бонусов, количество месяцев) частный деп жарияланған, оларға тек геттер/сеттер арқылы қол жеткізуге болады. Конструктор мен деструктор — әдепкі, параметры және көшірме конструктор жазылған; деструктор бонус-истории массивіне бөлінген жадты дұрыс босатады (удалить[]). этот нұсқауышы және терең көшіру (глубокая копия) — бонусИстория өрісі динамикалық жадыда (новый дубль[...]) сақталады. Көшірме конструктор с меньшими операторами и жад бөлініп, мәндер соль жерге көшириріледі — сондықтан бір объектінің бонусын өзгерту екінші объектіге әсер етпейді (main.cpp-ta emp2/emp1 мысалымен дәлелденген). Тұрақты объектілер мен констант әдістер — барлық геттерлер (getFullName, getPosition, getSalary, getMonthsCount, getBonus) const деп жарияланған, сондықтан олар const Сотрудник объектісінде де қауіпсіз шақырылады. Меньшие операторы (operator=) — өзін-өзине меньшіктеуден қорғайды, есть жадты босатып, жад бөлип, терең көшіру жасайды. Салыстыру операторы (operator==) — тапсырма шарты бойынша, екі қызметкердің аты-жөні мен лауазымы бірдей болса, олар тең деп есептеледі (жалақысы мент бонустар тарихы әртүрлі болса да). Файлдар құрылымы Работник.h — класс хабарламасы (өрістер мен әдістердің жарияланымы) Работник.cpp — класс әдістерінің іске асырылуы main.cpp — негізгі логика: объектілер жасау, көшіру, меншіктеу, салыстыру мысалдары README.md — осы файла Құрастыру (компиляция)
